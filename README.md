# Sindicato do trap

Criar o portal underground e hub interativo do movimento "O SINDICATO DO TRAP". Estética dark & red radical (preto fosco profundo, texturas grunge, ruído analógico, vermelho fosco de advertência) inspirada em Cactus Jack, OPIUM (Playboi Carti, Travis Scott), camping de XTRANHO do Matuê e A Nova Ordem Musical do TZ da Coronel. O hub deve ser disruptivo: interface de terminal/bunker confidencial com granulação de filme, player de fitas de áudio com trechos vazados das gravações do camping, dossiê com registros de vigilância dos membros, contador regressivo para os drops e vitrine tática do merch exclusivo.
