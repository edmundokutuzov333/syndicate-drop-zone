# Texture sources

Place licensed 2K CC0 material sources and official project decals here, outside `public/`. Each added file must be entered into `docs/camping-v3/ASSET-LICENSES.md` with source URL, author, licence, acquisition date and transformations. Never redraw the Sindicato seal or Xoyens logo.


The Fase 05 pipeline writes real CC0 2K maps into materials/ and materials.manifest.json. Do not commit guessed source IDs or synthetic maps. Generated PNG files use Git LFS; the source and license rows are maintained in docs/camping-v3/ASSET-LICENSES.md.
