# Referência do Estúdio Xoyens

Ficheiro de origem fornecido pelo proprietário do projecto: `Estúdio Criativo Sindicato do Trap copy.png` (1774×887 RGBA).

SHA-256 verificado contra o ficheiro recebido:
`998f637c62fad46c1459a0c85c99db79f2f799951b9d2c4c38b659ad2e193813`

O manifesto `reference-sectors.json` foi calculado a partir dessa imagem, com 24 sectores de azimute × 3 bandas de elevação, amostragem de cada segundo pixel e estatísticas CIE Lab D65 sRGB. O runtime de QA usa esse manifesto quando o operador não carrega a imagem original.

**Importante:** o PNG original ainda não está guardado neste directório. O conector GitHub disponível nesta execução permite criar ficheiros de texto e blobs codificados, mas não permite transferir directamente os bytes do anexo para o repositório. Não foi criado um PNG substituto nem uma imagem aproximada. Para activar o overlay A/B sem upload manual, copiar o ficheiro original exacto para `docs/camping-v3/reference/studio-pano.png` e confirmar o SHA acima. Nunca colocar a referência em `public/`.
